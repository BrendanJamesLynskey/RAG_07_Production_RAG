# RAG 07 — Production RAG

The gap between demo and production: eval pipelines with RAGAS, ARES, and Trulens, embedding drift detection and migration strategies, A/B testing frameworks, latency optimisation (caching, prefetching, query rewriting), multi-tenancy with namespace isolation and ACLs, citation and grounding patterns, cost modelling for the full RAG stack, and a taxonomy of the most common RAG failure modes.
